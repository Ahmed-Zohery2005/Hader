# حاضر — تطبيق الموظف (`apps/mobile`)

> **الجلسة 5 (المكتملة):** تطبيق فلاتر أندرويد للموظف + وضع الكشك المشترك.
> «حاضر… مش بس بصمت» — فيديو 8 ثوانٍ للوجه برقم عشوائي منطوق، فحوصات مفاجئة عادلة،
> وخصوصية محكومة بقانون 151/2020.

## المبادئ الحاكمة (من `Idea-V5.md`)

1. **الكاميرا الأمامية فقط** — لا يوجد سطر واحد في التطبيق يفتح الخلفية أو معرض الوسائط.
2. **توقيت السيرفر هو الحقيقة الوحيدة** — الأوفلاين يُحسب بساعة الرتابة
   (`SystemClock.elapsedRealtime`) المقترنة بآخر وقت سيرفر؛ ساعة الهاتف الحائطية لا تُعتد.
3. **الإنسان يقرر** — لا عقوبات آلية، والأوصاف تقنية محايدة (قاموس D11 واحد في `app_texts.dart`).
4. **الخصوصية بالتصميم** — الفيديو يُشفر AES-256-GCM في الطابور المحلي ويُمسح فور وصوله.

## الدفاع الإشاري الثلاثي (الجزء 3.7)

| المستوى | التنفيذ | الملف |
|---|---|---|
| 1 — FCM فوري | إشعار عالي الأولوية + ACK لحظي يثبّت المهلة من وصوله | `push/notification_defense.dart` |
| 2 — منبهات مشفرة | رد حضور الصباح يحمل جدول اليوم AES-256-GCM (بلا فحص المتابعة أبدًا) → منبهات محلية | `issue-capture-token` + `LocalAlarms` |
| 3 — لحظي عند الفتح | نبضة + استعلام الفحص النشط مع كل فتح | `heartbeat` + `homeProvider` |
| نبضة الاتصال | أي إشارة حياة + WorkManager كل 15–30 دقيقة (6 ساعات بلا نبضة = «مش متاح للفحص») | `HeartbeatWorker` |

## الاختبارات (بدون Flutter SDK في بيئة البناء)

- **`flutter test`** (6 ملفات): رياضيات الساعة — آلة الحالة العشر خطوات — طابور
  الأوفلاين (التراجع التصاعدي والاستحقاق) — مصنعو البطارية — تطبيع الهاتف — محايدة النصوص.
- **مرايا Python قابلة للتشغيل فورًا** (`tests/mobile_logic/` — من جذر المستودع):
  `python3 -m pytest tests/mobile_logic -q` — 21 اختبارًا تتحقق من نفس الخوارزميات
  والقيم الدستورية حرفيًا (بما فيها معادلة 0.37% لتخمين 3 من 4).

## وضع الكشك المشترك

حساب `kiosk_operator` واحد للجهاز (يُفعّل من التهيئة مع PIN الموقع):
فتح بالـ PIN (التحقق بدور الخدمة عبر `app.verify_pin` — الهاش لا يغادر السيرفر) →
اختيار العامل أو كوده الرباعي → تصوير 8 ثواني معزول لكل عامل (`kiosk_user_id`) →
قفل إلزامي بعد كل تسجيل. تسجيلات الكشك مقبولة تلقائيًا (إشراف بشري مباشر — قرار D21).

## عقود الدوال الطرفية المستخدمة

`verify-invite` → `complete-activation` → `issue-capture-token` (وفي الحضور: جدول
الصباح المشفر) → `r2-presign` (upload/offline_upload/selfie/view) → `register-capture`
→ `spot-check-actions` (ack/snooze) → `heartbeat` → `register-push-token`
→ `employee-actions` (اعتراض/سيلفي/سحب موافقة/فتح كشك).

> **قاعدة معمارية D40/D48:** كل كتابة تمر عبر الدوال الطرفية بجلسة المستخدم —
> التطبيق لا يكتب في الجداول مباشرة إلا وسم الإشعار المقروء (سياسة RLS صريحة).
